# 1.0.0-rc.1 graduation candidate

The existing five-package family is being frozen without feature expansion. Publication/qualification status is recorded separately; this note does not claim a public release.

All public signatures remain. Public API baselines now describe shipped contracts; AssemblyVersion is fixed at 1.0.0.0 for the stable 1.x line. The stable contract replaces the preview policy requiring recompilation on every version bump.

Preview cleanup: append buffers are copied before asynchronous work; returned in-memory history/hash/key bytes no longer alias retained state. Key Clear/Dispose becomes terminal for cryptographic use while zero-byte inspection remains available. Unknown SQLite access modes and invalid timeouts fail before I/O. Duplicate root names in checkpoint/signed-checkpoint JSON fail as ambiguous; unknown optional fields remain ignored. These are intentional behavioral corrections for invalid/unsupported use, not changes to supported persisted bytes.

Existing ledger epochs 1/2/3, canonical JSON v1/v2, checkpoint and signed-envelope encodings, SQLite schema and valid signing behavior are unchanged. No database migration or rewrite is required for qualified preview.7 stores. Keep external context/keys/checkpoints available; do not dispose dependencies during active operations.

Program.Main/RunAsync remain intentionally supported; CLI result/error categories and borrowed-writer behavior are documented. InMemory remains ephemeral. Native AOT analysis is not native link certification. No Merkle/replication/network/new format/remote signer/framework work is included.

Before final stable, qualify exact RC packages on the supported three-OS/net8 profile, public fresh-cache restores, unchanged-binary replacement and representative session/canonical-content consumers. See stable-contract.md and graduation-inventory.md.
